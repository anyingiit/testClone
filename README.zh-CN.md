## 关于本项目

testClone 是 anyingiit 在 2019 年 4 月用来试验向 GitHub 提交、推送代码的个人练习仓库。它最初的历史只有三次提交——*Initial commit*、*add an type*、*add a type*——而且每一次都只修改了 `README.md`，留下的正是旧版本 README 当作项目描述引用的那一行测试文字。[`CHANGELOG.md`](CHANGELOG.md) 里也只记录了一条 "Initial project structure"，仓库树中没有任何源代码文件、包清单或入口点。

除了那行原始文字之外，今天这里剩下的只是后来补上的仓库脚手架（本 README、`LICENSE`、`CONTRIBUTING.md`、issue 模板），作为文档基线添加进来。这个仓库里从来没有需要构建或运行的应用程序。

## 开始使用

### 前置条件

- 一个 `git` 客户端，用于克隆仓库并查看它简短的提交历史。不需要编译器、运行时或包管理器——仓库树中没有任何形式的清单文件。

### 安装

没有任何东西需要安装。这个仓库是一份历史测试产物，不是可分发的软件包：

```sh
git clone https://github.com/anyingiit/testClone.git
```

克隆后即可获得上面描述的完整历史，此外不需要任何设置步骤。

## 使用方法

没有命令或应用程序可以运行。请阅读 [`CHANGELOG.md`](CHANGELOG.md)，或浏览 git 提交历史，查看构成本仓库原始内容、时间为 2019 年 4 月的那几次提交。
